# CodexNotch 0.1.5

这一版让刘海不仅知道“Codex 正在运行”，也能看见任务内部正在发生什么。

## 新增

- 展示真实子 Agent 数量，点击任务即可展开父任务与子任务层级。
- 展示当前工具活动图标与动作名称，如生成图片、浏览网页、检查界面、修改代码和同步 GitHub。
- 展示 Queue 排队数量，只计算当前任务开始后追加、尚未处理的消息。

## 修复与优化

- 修复大型图片或界面截图记录可能覆盖子 Agent 创建事件的问题。
- 修复初始任务请求被误计为 Queue 的问题。
- 新状态不会进入 MacBook 物理摄像头区域，并继续复用统一尺寸与边框动画。

所有任务、工具和 Queue 信息仍只从本机 Codex 日志读取，不上传会话内容。
